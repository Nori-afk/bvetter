    Upload a workbook

    Use the same sheet layout the clinic already fills in. Nothing changes until the file passes every check — if anything is wrong, the upload is rejected and the current dataset is left exactly as it is.

    Workbook
    Drop your .xlsx file here, or click to choose
    Excel workbook, up to 25 MB
    What the file needs
    One row per consultation, with at least these columns:
    • consultation_id — unique for each consultation
    • year and month_no
    • barangay
    • diagnosis

    Other columns such as disease_category, symptom_cluster, animal_group and cases_reported are used when present. Because each consultation carries an id, uploading the same file twice is safe — nothing gets counted twice.

    Upload history

    Every version is kept. Switching back does not delete anything — it just changes which one the system reads.
