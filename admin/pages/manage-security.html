Email OTP (Active Method) When an admin signs in with the correct password, a 6-digit code is emailed to their registered address. The code expires after 10 minutes and allows 5 attempts. Veterinarian and pet owner accounts are not affected.
Edit Password Policy
Applies whenever a password is next set (registration, reset, account creation, password change). Existing passwords keep working, but anyone signing in with one that falls short of this policy is asked to update it before continuing.
Minimum Length
The four character requirements and the 12-character minimum are the enforced floor — they can be raised here but not switched off. Passwords are also rejected if they are a common word in disguise (Password123!, W3lcome!) or contain the account holder's own name or email.
Account Lifespan
Accounts with no login for this many days are blocked automatically, across every role. Enable the toggle on the security page to turn this on.

Session Timeout
Signed-in users are warned two minutes before the limit and signed out when it is reached. Only real activity — typing, clicking, scrolling — counts; a page left open on screen does not keep a session alive. Takes effect immediately for everyone currently signed in.
